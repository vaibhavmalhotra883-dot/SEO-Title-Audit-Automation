# Automated SEO Title Audit Tool 🚀

A Python-based automation tool built to scrape website pages, analyze HTML Title tags, evaluate SEO health based on live metrics, and export a production-ready audit sheet.

## Key Features
- **Smart Crawling:** Respects website domains and handles extraction with custom headers.
- **Advanced SEO Analysis:** Categorizes issues like Missing Titles, Duplicates, Too Short, and Too Long tags.
- **Actionable Output:** Generates a structured Excel/Google Sheet with Priority, Step-by-Step Fix Guides, and Business Impact (e.g., Keyword Cannibalization, CTR Drops).

## Tech Stack
- Python 3
- Requests & BeautifulSoup4
- Pandas
